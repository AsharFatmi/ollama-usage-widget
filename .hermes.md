# ollama-usage-widget

Native macOS menu bar app (Swift SPM, no Xcode, no signing) showing Ollama Cloud usage + local Ollama state in a popover.

## Project facts (read before any task)

- **Workspace:** /Users/ashar/Dev/ollama-usage-widget — NEVER move to ~/Documents, ~/Desktop, ~/Downloads (macOS TCC kills spawned workers there).
- **Stack:** Swift 6.3.3, swift-tools-version 6.0, macOS 14+, AppKit, XCTest. Strict concurrency: UI classes @MainActor, fetcher Sendable.
- **Cloud API:** GET https://ollama.com/api/usage with header `Authorization: Bearer <OLLAMA_API_KEY>` → `{"activity":{"cost":"0.00000","period":{"type":"last_4_weeks","starting_at":"...","ending_at":"..."},"models":[]},"limits":{"session":{"usage":0.003,"models":[{"name":"deepseek-v4-flash:0731","request_count":32}]},"weekly":{"usage":0.213,"models":[{"name":"deepseek-v4-flash:0731","request_count":5046},{"name":"web search","request_count":7}]}}}`. Undocumented endpoint; `period` param ignored; no plan/billing endpoints exist.
- **Local API:** GET http://localhost:11434/api/ps → `{"models":[{"name":"llama3.2:3b","size":2019553184,"size_vram":2019553184,"expires_at":"2026-08-19T06:00:00Z"}]}`. Empty models array when idle.
- **Key resolution:** KeychainStore.read() → EnvFileReader.ollamaKey() (parses ~/.hermes/.env for OLLAMA_API_KEY via EnvParser) → error state "No API key set — use Set Key…".
- **Keychain:** service `com.asharfatmi.ollama-usage-widget`, account `ollama-api-key`.
- **Design calls:** raw numbers not progress bars (no plan cap exposed); keep last-known data on failure, show error line, never crash; 5-min poll timer; refresh-on-open.
